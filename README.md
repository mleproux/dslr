# Introduction

This repo contains the 42 School project ¨dslr¨ or "Data Science x Logistic Regression", a continuation of the ft_linear_regression 42 project, the goal is to read a dataset, visualize it and train a logistic regression model to solve a classification problem.

# Dependencies

### Python version :
- Python 3.10

### Librairies :
- numpy
- pandas
- matplotlib

### Installation 
```sh
pip install numpy pandas matplotlib
```
